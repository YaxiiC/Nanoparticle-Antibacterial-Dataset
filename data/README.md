# Data files

| File | Purpose |
| --- | --- |
| `single_features.csv` | MIC regression dataset. |
| `single_MBC_features.csv` | MBC regression dataset. |
| `single_features_with_class.csv` | MIC dataset with class labels. |
| `enumerate_ag.csv` | Candidate Ag nanoparticle combinations. |
| `enumerate_ag_ecoli.csv` | Candidate Ag nanoparticle combinations for E. coli. |

Shared file paths are defined in `paths.py`.
